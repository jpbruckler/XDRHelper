# XDRHelper Module
## Description
Set of helper functions to streamline working with the Defender XDR API

## XDRHelper Cmdlets
### [Add-XdrDeviceTag](Add-XdrDeviceTag.md)
Adds one or more tags to one or more devices.

### [Assert-XdrAuthentication](Assert-XdrAuthentication.md)
Asserts valid authentication information exists for Defender.

### [Connect-XdrByAppId](Connect-XdrByAppId.md)
Authenticates to Microsoft Defender XDR using an AppID and App secret.

### [Disconnect-Xdr](Disconnect-Xdr.md)
Removes authentication token from local memory.

### [Get-XdrDevice](Get-XdrDevice.md)
Retrieves device information by Device ID or by OData 4 query.

### [Remove-XdrDeviceTag](Remove-XdrDeviceTag.md)
Removes one or more tags from one or more devices.
